# My Collection

个人收藏夹 —— 开发与自托管路上觉得好用的工具、服务和资源，持续整理中。

## 为什么有这个仓库

零散收藏太多，索性整理成公开清单：一是自己回头好找，二是顺手分享给有同样需求的人。

## 收藏分类

| 分类 | 说明 |
|---|---|
| [在线工具](collections/online-tools.md) | 即开即用的网页版小工具 |
| [建站与部署](collections/deploy.md) | 免费额度友好的建站平台与部署服务 |
| [自托管资源](collections/self-hosted.md) | 值得自己部署一份的开源项目 |

## 维护方式

- 遇到好东西随手加一条，每月集中整理一次
- 只收自己实际用过的，不堆砌列表
