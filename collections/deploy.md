# 建站与部署

免费额度友好、个人项目够用的建站平台。

| 平台 | 免费档要点 | 适用 |
|---|---|---|
| [Cloudflare Pages](https://pages.cloudflare.com/) | 每月 500 次构建、带宽不限量 | 静态站与全栈项目的首选 |
| [Cloudflare Workers](https://workers.cloudflare.com/) | 每天 10 万次请求 | 边缘函数 / API / 代理 |
| [GitHub Pages](https://pages.github.com/) | 公开库免费 | 纯静态、文档站 |
| [Vercel](https://vercel.com/) | Hobby 档 100GB 带宽/月 | Next.js 生态最顺滑 |
| [Netlify](https://www.netlify.com/) | 100GB 带宽/月 | 静态站 + 表单 + Functions |
| [Deno Deploy](https://deno.com/deploy) | 有免费档 | Deno/TS 边缘应用 |
