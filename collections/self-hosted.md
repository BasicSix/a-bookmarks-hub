# 自托管资源

值得自己部署一份的开源项目，都是长期活跃、社区成熟的那种。

| 项目 | 用途 | 一句话短评 |
|---|---|---|
| [Uptime Kuma](https://github.com/louislam/uptime-kuma) | 拨测监控 | 颜值在线的自托管 Uptime Robot |
| [Vaultwarden](https://github.com/dani-garcia/vaultwarden) | 密码管理 | Bitwarden 兼容服务端的轻量 Rust 实现 |
| [Memos](https://github.com/usememos/memos) | 碎片笔记 | 自托管 flomo，SQLite 单文件起步 |
| [FreshRSS](https://github.com/FreshRSS/FreshRSS) | RSS 阅读器 | 老牌自托管 RSS，手机客户端齐全 |
| [Nginx Proxy Manager](https://github.com/NginxProxyManager/nginx-proxy-manager) | 反代管理 | 点点鼠标配反代和证书 |
| [MinIO](https://github.com/minio/minio) | 对象存储 | S3 兼容，备份和图床的底座 |
| [Grist](https://github.com/gristlabs/grist-core) | 多维表格 | 开源版 Airtable |
| [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) | 资源索引 | 先逛这个列表再决定部署什么 |
