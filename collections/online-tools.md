# 在线工具

即开即用、不用装的网页版工具，个个都经得起日常使用。

| 工具 | 用途 | 一句话短评 |
|---|---|---|
| [CyberChef](https://gchq.github.io/CyberChef/) | 编解码/加解密 | GCHQ 出品的「网络瑞士军刀」，Base64/URL/时间戳一把梭 |
| [Excalidraw](https://excalidraw.com/) | 手绘白板 | 画架构草图和流程图最舒服的工具，支持协作 |
| [tldraw](https://www.tldraw.com/) | 无限画布 | 手感极好的白板，`/` 键呼出一切 |
| [Regex101](https://regex101.com/) | 正则调试 | 逐字符解释匹配过程，正则学习第一站 |
| [Crontab.guru](https://crontab.guru/) | cron 表达式 | 输入表达式直接翻译成人话 |
| [Can I use](https://caniuse.com/) | 浏览器兼容 | 查 API/特性兼容性的事实标准 |
| [transform.tools](https://transform.tools/) | 代码转换 | JSON 转 TS 类型、YAML 等几十种转换 |
| [JSON Hero](https://jsonhero.io/) | JSON 查看 | 把 JSON 分享给同事时的体面方式 |
| [fast.com](https://fast.com/) | 测速 | 打开就测，无广告 |
